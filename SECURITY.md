# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Below 1.0 | No |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting from this repository's **Security** tab if it is available. Otherwise, open an issue that asks for a private contact channel, without including vulnerability details.

Include the affected version, the impact, and the steps needed to reproduce the problem. This is a personal sandbox, so no response time is guaranteed.

## Scope

The application is a static site with no backend, accounts, forms, or stored user data. Findings in the build, dependencies, CI workflow, or published files are in scope.
